# Port Scanner

## What This Does
Scans a target IP address for open network ports. Helps identify security risks.

## How It Works
1. Tries to connect to common ports
2. If connection works → port is OPEN
3. If connection fails → port is CLOSED

## Common Ports Checked
- 21 (FTP) - File transfer
- 22 (SSH) - Secure shell
- 80 (HTTP) - Web traffic
- 443 (HTTPS) - Secure web
